## Problem and resulting behavior

A task can currently have a one-character title or a past due date. This PR
trims titles, requires at least three characters, and rejects a newly supplied
due date before today's UTC date with a field-specific HTTP 400 response.
Today, future dates, and null are valid. Updating a task's status or description
preserves an existing overdue date when due_date is omitted.

## Validation

`python manage.py test tasks.tests.test_validation tasks.tests.test_baseline`

Tests cover blank/short/long titles, trimming, today/future/past/null dates,
malformed dates, invalid updates, and an overdue task's partial update.
