## Problem and resulting behavior

Any authenticated user can currently list or access another user's tasks.
This PR scopes the shared queryset to the authenticated owner, protecting list,
retrieve, PUT, PATCH, and DELETE consistently. Alice accessing Bob's task
receives HTTP 404 and Bob's data remains unchanged. Staff users follow the
same isolation rule. Ownership remains assigned by the server and read-only.

## Validation

`python manage.py test tasks.tests.test_ownership tasks.tests.test_baseline`

Tests cover list isolation, cross-user reads/writes/deletes, own-task access,
forged owner fields on creation/update, staff isolation, and anonymous access.
